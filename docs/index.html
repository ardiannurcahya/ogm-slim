ENGINEERING EXCELLENCE

Built for Serious AI Pair Programming

Everything your AI agent needs to understand massive multi-package codebases and maintain continuous operational learnings.

Cross-File AST Call Graph

Instantly maps symbols, functions, methods, structs, and interfaces across multiple files and packages. Automatically detects downstream callers, dependencies, and type contracts.

  • Louvain modularity community detection
  • PageRank hub centrality ranking
  • SHA-256 incremental hash cache

Bi-Temporal Agent Memory

Separates raw observation logs (Episodes) from verified architectural conclusions (Memories). AI agents anchor bug fixes, runbooks, and design decisions directly to symbol keys.

  • Composite ranking: BM25 + Confidence + Recency
  • Automatic memory superseding & invalidation
  • Citations graph linking memories to proof logs

Native Model Context Protocol (MCP)

Zero friction connection with Claude Desktop, Cursor, Roo-Code, and Antigravity. Equipped with 12 atomic tools for real-time querying, observing, committing, and indexing.

  • 100% compliant with standard MCP 1.5 specification
  • Stdio & SSE transport support
  • Isolated multi-dataset project namespaces

Ultra-Fast Local SQLite WAL

Zero cloud subscriptions or external databases required. All data resides in a single, high-performance embedded SQLite database using Write-Ahead Logging for lightning-fast reads.

  • Single file portability (`~/.ogm/ogm.db`)
  • Zero memory leaks with parallel worker pooling
  • Full-text FTS5 BM25 search index

Why Vector RAG Alone Fails for Code

Code is a deterministic graph of call hierarchies and exact contracts, not just loose text similarity.

ogm-slim serve --port 8765

app.ts
import { indexCodebaseDirectory, recallMemories, commitMemory } from 'ogm-slim';

// Index codebase into knowledge graph
await indexCodebaseDirectory('./src', 'my-project');

// Recall relevant memories with hybrid ranking
const results = await recallMemories('WASM lifecycle', 'my-project');
console.log(results);
